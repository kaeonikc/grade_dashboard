# Tasks: grade_web

Each task is a vertical slice that leaves the app working. Status is tracked in `.app/state.json` (run
`state.py status`), not here. Paths are relative to the grade_dashboard repo root. Commands, run from the repo root:
pytest `python3 -m pytest tests/`; node `node --test 'web/tests/*.test.js'` (quoted glob: `node --test web/tests/`
fails on Node 24, which treats the directory as one file). Every task also keeps the existing suite green with no
edit to existing test files, and leaves grade-tui (`rust_tui/`) untouched. "M<n>" = the manual checklist in SPEC
"Test plan".

v1 uses all 10 tasks. If the plan runs over, move these to the backlog first (REQUIREMENTS "v1 scope"): Undo last
save (S9, in T7), then editing in the wide table (S5.4, in T8).
